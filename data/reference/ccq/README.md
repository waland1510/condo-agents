# Reference corpus: Civil Code of Québec, divided co-ownership

Condensed, article by article, from the English text of Book Four, Title
Three, Chapter III of the Civil Code of Québec (CQLR c. CCQ-1991, articles
1038 to 1109). These are working summaries written for this repository, not
the official text. Always verify against
https://www.legisquebec.gouv.qc.ca/en/document/cs/ccq-1991 before relying on
an article.

The corpus is shared across every building (`corpus: reference`) and carries
no scope of its own; `ScopeFilter` admits it alongside the scoped building
documents.
